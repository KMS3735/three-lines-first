# 세 줄 먼저 (Three Lines First)

**받은 공공 안내문을 찍으면, 해야 할 일이 맨 위에 보이는 안드로이드 앱**

세금, 과태료, 건강검진, 복지 안내문을 촬영하면 AI가 **무슨 안내인지 · 해야 할 일 · 언제까지·얼마·어디서** 세 줄과 **"안 하면"** 경고 한 줄, 할 일 체크박스로 정리해 줍니다. 요약 속 날짜와 금액은 원문과 코드로 한 번 더 대조하고, 읽은 뒤에는 달력 등록 · 전화 · 가족 공유까지 버튼 하나로 이어집니다.

> 현재 개발 중인 프로젝트입니다. 아래 기능과 구조는 구현 목표를 기준으로 작성했습니다.

## 왜 만들었나

공공 안내문은 삶에 직접 영향을 주지만, 법 조항과 행정 용어 사이에 "무엇을, 언제까지, 어떻게"가 묻혀 있습니다. 실제로 한 청년 지원사업은 공식 공고의 접수 마감(5월 29일)이 본문에 묻혀, 인터넷에 "상시 신청"이라는 잘못된 요약이 돌기도 했습니다.

사진을 찍어 AI에게 물어보는 방법은 이미 있지만, 질문을 직접 입력하고 긴 답변을 읽어야 해서 정작 안내문이 어려운 사람에게는 또 하나의 장벽이 됩니다.

**주요 사용자:** 어르신, 발달장애인, 외국인 주민처럼 공공 안내문을 이해하기 어려운 사람과 그 가족

## 이미 있는 도구와 무엇이 다른가

사용 흐름은 **찍는다 → 읽는다 → 한다** 세 동작으로 끝납니다.

| 비교 항목 | 범용 도구 (사진 검색, AI 챗봇) | 세 줄 먼저 |
| --- | --- | --- |
| 사용 방법 | 앱 실행, 촬영, 질문 직접 입력 | 큰 촬영 버튼 하나 |
| 결과 형식 | 매번 길이와 구성이 다른 긴 답변 | 항상 같은 세 줄 + 경고 한 줄 + 할 일 |
| 정확성 확인 | 사용자가 스스로 판단 | 날짜·금액 자동 대조, 원문 나란히 보기 |
| 개인정보 | 사진 전체가 외부로 전송 | 기기 안에서 개인정보를 가린 텍스트만 전송 |
| 읽은 다음 | 사용자가 직접 기억하고 처리 | 달력 등록, 전화 걸기, 가족 공유, 마감일 알림 |
| 화면 | 일반 글씨 크기 | 큰 글씨, 고대비, 음성 읽어주기 |

## 세 줄 형식

요약은 자유 서술이 아니라 항상 같은 순서와 역할을 갖습니다. 사용자는 매번 같은 자리에서 같은 정보를 찾고, 코드는 각 줄을 따로 검증할 수 있습니다.

| 줄 | 역할 | 예시 (아파트 관리비 고지서) |
| --- | --- | --- |
| 1줄 | 무슨 안내인지 | 아파트 관리비 고지서예요. |
| 2줄 | 해야 할 일 | 이번 달 관리비를 내셔야 해요. |
| 3줄 | 언제까지, 얼마, 어디서 | 10월 31일까지 152,000원을 은행이나 인터넷뱅킹으로 내요. |
| 경고 | 안 하면 어떻게 되는지 | 기한이 지나면 연체료가 붙을 수 있어요. |
| 할 일 | 체크박스 목록 | □ 관리비 납부하기 |

## 주요 기능

| 단계 | 기능 | 설명 |
| --- | --- | --- |
| 시작 | 개인정보 동의 | 첫 실행 시 어떤 정보가 외부 AI로 전송되는지 그림으로 안내하고 동의를 받음 |
| 촬영 | 촬영 안내 화면 | "종이를 평평하게, 밝은 곳에서, 네 모서리가 보이게" 안내와 가이드 틀 표시 |
| 촬영 | 글자 인식 | ML Kit 글자 인식(한국어)으로 기기 안에서 원문 텍스트 추출 |
| 촬영 | 개인정보 자동 가림 | 주민등록번호, 개인 휴대전화, 계좌번호, 주소, "성명:" 뒤 이름을 가린 뒤에만 AI로 전송 |
| 요약 | 세 줄 먼저 요약 | 세 줄 + 경고 한 줄을 큰 글씨 카드로 표시 |
| 요약 | 할 일 체크박스 | "신분증 챙기기", "병원 예약" 같은 할 일을 체크 목록으로 제공 |
| 요약 | 원문 나란히 보기 | 요약 아래 원문 사진을 항상 표시하고 "효력은 원문을 따릅니다. 중요한 내용은 가족이나 해당 기관에 확인하세요"를 고정 표기 |
| 요약 | 이해가 안 돼요 | 누르면 더 쉬운 말로 다시 요약 |
| 행동 | 소리로 읽어주기 | TextToSpeech로 세 줄을 음성 안내 |
| 행동 | 달력에 등록 | 마감일을 버튼 하나로 기기 달력에 추가 |
| 행동 | 바로 전화 걸기 | 원문에서 기관 대표번호를 찾아 전화 버튼으로 제공 |
| 행동 | 가족에게 보내기 | 요약과 원문 사진을 메신저·문자로 공유, 이후 Firebase로 자녀 계정 자동 공유 |
| 행동 | 마감일 알림 | 마감일 3일 전과 당일에 알림 |
| 설정 | 내 모드 | 쉬운 말, 큰 글씨 설정을 한 번 저장하면 모든 문서에 적용 |
| 설정 | 원문 사진 보관 | 요약 후 원문 사진을 저장할지 선택, 저장하지 않으면 요약 텍스트만 남김 |

### 접근성 기준

- 본문 글씨 크기 기본 20sp 이상, 큰 글씨 모드에서 28sp 이상
- 모든 버튼은 48dp 이상의 터치 영역과 아이콘 + 글자를 함께 표시
- 배경과 글자의 색 대비를 높게 유지하고, 경고 줄은 색과 아이콘을 함께 사용
- 모든 이미지와 아이콘 버튼에 `contentDescription`을 달아 TalkBack으로 사용 가능

## 동작 방식

![AI 요약 처리 흐름](docs/images/summary-pipeline.png)

1. **글자 인식과 개인정보 가림은 기기 안에서 처리합니다.** 원문 사진은 외부로 나가지 않고, 가려진 텍스트만 AI에 보냅니다.
2. **AI 응답의 형식을 검사합니다.** 정해진 JSON 형식이 아니거나 필수 줄이 비어 있으면 화면에 띄우지 않고 한 번 다시 요청합니다.
3. **날짜와 금액은 규칙 코드로 대조합니다.** 원문과 요약에서 정규식으로 날짜·금액을 뽑아 같은 형식으로 바꾼 뒤(`2026. 10. 31.`, `10월 31일` → `2026-10-31` / `152,000원`, `15만 2천원` → `152000`), 요약의 값이 모두 원문에 있는지 검사합니다. 없으면 한 번 다시 요약하고, 그래도 다르면 경고 배지를 붙입니다.
4. **확신이 없을 때는 사용자에게 묻습니다.** 날짜가 여러 개면 "까지", "마감", "기한" 주변 날짜를 우선 고르고, 그래도 불확실하면 후보를 보여 주고 고르게 합니다.
5. **최종 판단은 원문 기준입니다.** 요약 화면에는 항상 원문이 함께 표시되고, 전화 버튼으로 기관에 바로 확인할 수 있습니다.

### AI 출력 형식

```json
{
  "line1_what": "아파트 관리비 고지서예요.",
  "line2_todo": "이번 달 관리비를 내셔야 해요.",
  "line3_when_where": "10월 31일까지 152,000원을 은행이나 인터넷뱅킹으로 내요.",
  "warning": "기한이 지나면 연체료가 붙을 수 있어요.",
  "todos": ["관리비 납부하기"],
  "deadline": "2026-10-31",
  "amounts": [152000]
}
```

- 마감일을 `deadline`(`YYYY-MM-DD`)으로 따로 받아 자동 대조, 달력 등록, 마감일 알림에 그대로 씁니다.
- 원문에 없는 내용은 쓰지 않고, 찾을 수 없는 항목은 `null`로 둡니다.

### 데이터 저장

| 테이블 | 주요 열 | 내용 |
| --- | --- | --- |
| `notice` | id, title, masked_text, image_path, deadline, amount, phone, verified, created_at | 안내문 한 건과 대조 결과 |
| `summary` | notice_id, line1_what, line2_todo, line3_when_where, warning | 세 줄 요약과 경고 문구 |
| `todo` | id, notice_id, content, done | 할 일 체크박스 |

원문 사진 보관을 끄면 `image_path` 없이 요약 텍스트만 남습니다.

## 시작하기

모든 개발과 빌드는 Android Studio에서 진행합니다. 프로젝트 설정, 의존성, 권한, 개발 순서는 [Android Studio 개발 계획서](docs/android-studio-plan.md)에 정리했습니다.

1. 저장소를 클론하고 Android Studio로 엽니다.
   ```bash
   git clone https://github.com/KMS3735/three-lines-first.git
   ```
2. [Google AI Studio](https://aistudio.google.com/)에서 Gemini API 키를 발급받아 `local.properties`에 추가합니다. 이 파일은 Git에 올라가지 않습니다.
   ```properties
   GEMINI_API_KEY=발급받은_키
   ```
3. 가족 자동 공유를 쓰려면 [Firebase 콘솔](https://console.firebase.google.com/)에서 Android 앱을 등록하고 `google-services.json`을 `app/` 폴더에 넣습니다.
4. 카메라 기능을 쓰려면 에뮬레이터 대신 실제 안드로이드 기기에서 실행하는 것을 권장합니다.

## 개인정보 보호

- 첫 실행 때 어떤 정보가 외부 AI로 전송되는지 안내하고 동의를 받습니다.
- 개인정보는 AI로 보내기 전에 기기 안에서 먼저 가립니다.
- 원문 사진은 외부로 전송하지 않고, 기기에 보관할지도 사용자가 고릅니다.
- 기기 안 글자 인식으로 끝내 읽히지 않는 안내문은, 사용자가 다시 동의한 경우에만 사진을 AI로 보냅니다.
- 요약은 이해를 돕기 위한 참고용이며, 효력은 항상 원문을 따릅니다.

# 세 줄 먼저 – AI 도구 활용 내역

수업에서 제시한 "Claude, ChatGPT, Gemini를 적극 활용하고 AI 에이전트 활용을 먼저 계획한다"는 조건에 따라, 이 프로젝트에서 AI를 어디에 어떻게 썼는지 기록합니다.

## 1. AI 활용 구분

이 프로젝트의 AI는 두 가지로 나뉩니다.

| 구분 | 도구 | 역할 |
| --- | --- | --- |
| 앱 기능으로 쓰는 AI | Gemini API | 안내문을 세 줄 요약, 쉬운 말로 다시 요약 |
| 개발에 쓰는 AI | Claude (Claude Code), ChatGPT, Gemini | 기획 검토, 문서 작성, 코드 작성과 디버깅 |

## 2. 활용 원칙

- **AI는 초안을 만들고, 검증은 직접 합니다.** AI가 만든 문서는 기획 내용과 대조하고, AI가 만든 코드는 실제 기기에서 실행하고 단위 테스트로 확인한 뒤 반영합니다.
- **정확성이 중요한 부분은 규칙 코드로 검증합니다.** 앱 안의 AI 요약도 같은 원칙으로, 날짜·금액은 정규식 대조를 통과해야 그대로 표시합니다.
- **개인정보와 키는 AI에 넘기지 않습니다.** 실제 안내문 원본, API 키는 개발용 AI 도구에 입력하지 않습니다.
- **활용 내역을 기록합니다.** 무엇을 맡겼고, 무엇을 확인하거나 고쳤는지 아래 표에 남깁니다.

## 3. 단계별 활용 계획

| 단계 | AI에 맡기는 일 | 직접 하는 일 |
| --- | --- | --- |
| 기획 | 유사 서비스 조사, 계획서 문장 다듬기 | 문제 정의, 기능 범위 결정 |
| 설계 | 화면 목업, 패키지 구조, Room 스키마 초안 | 수업 내용과 맞는지 검토, 최종 결정 |
| 구현 | Activity·레이아웃·정규식 코드 초안, 오류 원인 분석 | 실기기 실행, 단위 테스트, 코드 이해와 수정 |
| 검증 | 테스트용 안내문 문장 생성 | 실제 안내문 샘플로 정확도 점검 |
| 보고 | 진행 보고서 초안 정리 | 결과 확인, 발표 |

| 10월 | Claude | README, Android Studio 개발 계획서, 화면 목업 초안 작성 | 계획서와 내용 대조, 기능 범위 수정 |
| 10월 | Claude | 강의자료(Week01~06)를 참고한 개발 계획 보완 | Room, Thread·Handler 등 수업 내용 적용 여부 확인 |
